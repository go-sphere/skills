# Archive

Historical guides kept for reference. They are not maintained and do not describe the
current skills.

- [dev.md](dev.md) — the 12-stage AI-agent collaboration workflow, from a short PRD and a
  prototype to a shipped release, with per-stage chapters under `dev/`.
- [prompt.md](prompt.md) — per-round prompt templates for that workflow, with chapters
  under `prompt/`.

Both were written for a larger skill pipeline that has since been trimmed and renamed. Skill
names in them may no longer exist; the top-level [README.md](../../README.md) lists the
current skills.
